
# Chef's Menu Manager

## Project Description

Chef's Menu Manager is a React Native mobile application developed for Christoffel's Restaurant. The application allows the chef to manage restaurant menu items through a simple and user-friendly interface.

## Application Features

- Add new menu items.
- View all menu items.
- Edit existing menu items.
- Delete menu items.
- Search for dishes by name.
- Filter menu items by course.
- Calculate the total number of menu items.
- Calculate the average menu price.
- Display the number of dishes in each course.
- Validate user input.
- Display success and error messages.

## Technologies Used

- React Native
- Expo
- TypeScript
- Visual Studio Code

## Menu Information

Each menu item contains:
- Dish name
- Description
- Course
- Price

Available courses:
- Starter
- Main Course
- Dessert

## How to Run the Application

1. Download or clone the GitHub repository.
2. Open the project in Visual Studio Code.
3. Open the terminal.
4. Run npm install.
5. Run npx expo start.
6. Open the application using an Android emulator or Expo Go.
